# AI-Generated AGI Architecture Proposals — Research Packet

## Purpose

Collect, preserve, and compare AGI architecture proposals generated by at
least 8 distinct AI systems, so that different architecture ideas become
comparable and useful for Cognitive-OS planning.

## Status

**Scaffolding stage.** The collection methodology, standardized prompt, and
comparison schema are defined below and in `prompts.md` / `comparison.csv`.
Raw outputs in `raw_outputs/` are placeholders until each system has been
queried; no AI output is fabricated in this packet.

## Collection Method

1. Use the standardized prompt in `prompts.md` for every system.
2. Any per-model adaptation must be documented in `prompts.md`.
3. Save the raw (or minimally cleaned) response as
   `raw_outputs/<system>.md`, with model/version and date recorded.
4. Fill one row per system in `comparison.csv`.
5. Synthesize findings in `summary.md`.
